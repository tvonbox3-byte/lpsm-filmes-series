OBJETIVO DESTA VERSÃO
1. Voltar para o método de catálogo que JÁ FUNCIONOU:
   app -> endpoints /api/device/catalog/... do backend.

ATUALIZAÇÃO DO APK
- O GitHub Actions gera SOMENTE APK RELEASE assinado pela chave fixa.
- Cada build recebe versionCode maior automaticamente.
- O app consulta update.json.
- Quando encontra versão nova, baixa o APK sozinho.
- Você NÃO precisa abrir o GitHub e baixar o APK.
- Android/BlueStacks ainda mostra a confirmação final de Instalar/Atualizar.
- Em Android 8+, na primeira vez pode pedir “Permitir desta fonte”.

IMPORTANTE SOBRE A ASSINATURA
Se o APK instalado hoje ainda tiver assinatura DEBUG antiga, o Android não deixa
uma RELEASE atualizar por cima. Nesse caso, instale a 1.6.0 RELEASE manualmente
UMA ÚLTIMA VEZ. Depois não desinstale mais: as próximas versões usam a mesma chave.
