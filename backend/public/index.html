Como conectar a persistência online

Primeiro baixe o backup dos cadastros. No SQL Editor do seu projeto Supabase, execute o SQL de configuração. No serviço backend do Render, configure SUPABASE_URL e SUPABASE_SECRET_KEY com os dados desse projeto. A chave deve ficar somente no servidor.

Depois do deploy, abra o painel neste mesmo navegador e confira a recuperação. Se necessário, use Restaurar backup. A confirmação é o indicador “Persistência online”.
